# The House

A small browser roguelike prototype built around a supernatural casino.

## Play
- Move with WASD or arrow keys.
- Press Enter near doors/tables/elevator.
- Space dashes.
- Z or X attacks during combat.
- Blackjack uses Enter to hit and S to stand.
- Escape leaves tables/counters.

## Core loop
Explore a floor, fight for chips, take risks at casino games, buy useful upgrades, and descend deeper.

The House starts generous. As the run becomes more successful, its suspicion rises and the casino's behavior changes.

## Run it
Open `index.html` in a browser. No build tools or dependencies are required.

## Art direction
Muted midnight blues, warm brass, dusty gold, burgundy accents, and chunky pixel silhouettes. The casino is mysterious and stylish rather than horror-themed.
